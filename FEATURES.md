# Still: feature map

Everything Still has today, read from the code. ✅ shipped in 2.0.0 (`main`) · 🚧 in progress (branch named) · 🧪 experimental.
Paths: `still/` = Windows host (WPF, WebView2), `still-ui/src/` = the React interface both hosts load, `mac/Sources/Still/` = Mac host (AppKit, WebKit).

**Rule:** any commit that adds, changes or removes a feature updates this file in the same commit.

## Browser and tabs

- ✅ **Tabs**: open, close, pin, duplicate, mute, reorder, sleep; saved in `state.json` (`Models.cs` `SavedState`, written via `.tmp` then `.bak` swap).
- ✅ **Restore tabs**: reopens last session's tabs on start, every normal window with its own tabs (each tab saved with its `Window`); windows closed one after another within 15 seconds of the last all come back; never private tabs or a temporary window's; Preferences `RestoreTabs` (`SavedTabs`, `RestoreOtherWindows`; Mac `saveAll`, `restoreOtherWindows`, built but not run; tests/desktop/session.py).
- ✅ **Reopen closed tab**: Ctrl+Shift+T, plus a recently closed list (`recent`/`recentPick` in `MainWindow.Shell.cs`).
- ✅ **Recent-tab switcher**: Ctrl+Tab flips to the last tab; holding Ctrl shows an MRU list (`MainWindow.Tabs.cs` `SwitchRecent`).
- ✅ **Cycle tabs**: Ctrl+Alt+Left/Right moves through tabs in strip order (`CycleTabs`).
- ✅ **Find a tab**: Ctrl+K sheet filters open tabs (`MainWindow.Panels.cs`).
- ✅ **Tab groups**: named, colored, collapsible; members stay adjacent in the strip (`MainWindow.Tabs.cs`, `TabGroup`).
- ✅ **Split view**: two tabs side by side in one window, resizable, swappable; one pair per window (`StartSplit`). Swap sides, 50/50 and Separate tabs are in a split tab's right-click menu.
- ✅ **Tab layout**: Classic (tabs on top) or Modern (resizable left sidebar); Preferences `TabLayout`, `SidebarWidth`.
- ✅ **Multiple windows**: one process, shared history/bookmarks/settings; each window owns its tabs (`MainWindow.Windows.cs`).
- ✅ **Temporary sign-in windows**: windows Still opens itself for a sign-in (Composio's Get a key page, an app's Composio sign-in) are temporary: never saved to the session, closed with the last normal window, and never given links from other apps or a companion's tabs; with only temporary or private windows left the saved session stays as it was (`temporary`, `Unsaved`, `Home`). While setup is showing, a link from another app or an AI app's sign-in page opens in one of these, in front of setup, never as a tab behind it (`OpenOverSetup`, Mac `openOutside`; tests/desktop/welcome.py).
- ✅ **Move tabs between windows**: drag out (setting "Drag tabs into their own window", off by default) or Move to; live page moves without reload.
- ✅ **Private window**: every tab InPrivate and unsaved; Ctrl+Shift+N (`OpenIncognito`). 🚧 (`still-2.10/stage-05-profiles`) Each incognito window has its own private engine profile on Windows too (`ownPrivateProfile`), so two never share a sign-in; private tabs in a normal window share one.
- 🚧 **Incognito AI chats** (`still-2.10/stage-01-incognito`): a chat in a private window keeps nothing. It's never in chats.json, history, Resume or another window (`privateChats`, `Ephemeral`). Its AI app runs in `ai/incognito/<window>` with its attachments and failure logs; closing the window stops its runs and deletes the folder, and the next start sweeps what a crash left. Its pages, web_search and read_url use the private engine profile (the InPrivate profile on Windows, the window's own private website data on the Mac), never either persistent profile, and it uses only the tabs it opened. 🚧 (`still-2.10/stage-05-profiles`) Connected apps are off there: the plugin tools aren't offered (`--no-plugins`), a call is refused, and the chat says so. remember, update_knowledge, forget, save_file and offer_routine are refused, no site rule is saved and drafts stay in memory. The chat says the AI's provider and the sites it visits still get what's sent, and the provider's app may keep its own record (`tests/desktop/incognito.py`).
- 🚧 **Incognito runs ask the AI app not to save** (`still-2.10/stage-06-runtime`): from an incognito chat, Claude Code runs with `--no-session-persistence` and ChatGPT with `exec --ephemeral` (both documented in their `--help`), so each turn starts a new session that carries the chat so far, and the chat says the app is told not to save it. Grok has no such option, so its chat still says it may keep its own record.
- ✅ **Address bar**: search or URL; local history/bookmark suggestions, learned typed→picked ranking (`suggestions.ts`, `AddressPick`); never fetches icons or sends keystrokes.
- ✅ **still:// pages**: still://chats (also still://chat-history), new, library, companions, skills, settings, history, bookmarks, downloads, passwords, profiles, import, extensions, about and help open Still's own pages; any case, spaces read as dashes; typing still:// suggests them; an unknown one says so instead of searching (`STILL_PAGES`, `go` in App.tsx; tests/desktop/stillpages.py). Typed in the address bar only: bookmarks and links to still:// don't open them.
- ✅ **Search engine**: Google, Bing or DuckDuckGo (Preferences `SearchEngine`).
- ✅ **New tab page**: the companion home (chats, ideas) or "sites" (speed dial, suggested sites, open tabs); Preferences `NewTab`.
- ✅ **Try one of these**: up to three concrete one-click tasks under the home's message box, each with a one-line why, strongest first: a project the companion remembers ("From Maya's memory"), a connected app it works in ("Gmail is connected"), a real open tab (never a private, loading, chat or non-web one), then its role's tasks that match the work the user picked in setup, then its role's own. They follow the context as it changes; with nothing to go on there are no cards at all (`homeIdeas` in suggestions.ts; still-ui/tests/suggestions.test.ts, tests/desktop/ideas.py)
- ✅ **Bookmarks**: Ctrl+D, bookmarks bar, edit/move/remove, import/export HTML (`MainWindow.Panels.cs`).
- ✅ **History**: searchable panel, remove entries, clear all (`MainWindow.Panels.cs`).
- ✅ **Downloads**: card on start, progress ring, open/show/cancel, choose folder (`MainWindow.xaml.cs`, Preferences `DownloadFolder`).
- ✅ **Reader mode**: Ctrl+Shift+R, Mozilla Readability on a copy of the page (`MainWindow.Actions.cs`, `Assets/Readability.js`).
- ✅ **Hide an element**: pick an element to hide; per-site rules re-applied on load (`PickHidden`, `SavedState.Hidden`).
- ✅ **Find in page, zoom, picture-in-picture**: toolbar and shortcuts (`find`, `zoom`, `pictureInPicture` in `MainWindow.Shell.cs`).
- ✅ **Full screen**: F11 covers the monitor incl. taskbar; video full screen fills the window instantly (`MainWindow.FullScreen.cs`).
- ✅ **Pop-ups**: sized `window.open` gets a small window titled with its site; unrequested pop-ups blocked, allow per site (`MainWindow.Popups.cs`).
- ✅ **App links**: discord:, mailto: etc. ask in the permission bar, remember Allow per site+app, refuse abusable schemes (`MainWindow.AppLinks.cs`).
- ✅ **Site permissions**: camera/mic/location etc. asked in Still's own bar; denied after 90 s unanswered (`MainWindow.Permissions.cs`).
- ✅ **Permissions button**: in the toolbar where split view's button was: Allow, Ask or Block per site for camera, microphone, location, notifications, clipboard, pop-ups, automatic downloads, autoplay and sound, screen sharing, MIDI and USB; applied at once and kept (a private window's only until it closes); Reset; a link to all site settings; a dot while the page has the camera, mic or location on (`SitePermissions.tsx`, `MainWindow.Permissions.cs`, Mac `Tools.swift`).
- ✅ **Page dialogs**: alert/confirm/prompt shown inside Still, not as Windows dialogs (`dialogAnswer`).
- ✅ **Upload card**: a site's file picker opens a card of recent matching files, copied image first; picker intercepted via CDP (`MainWindow.FilePaste.cs`, `UploadCard.tsx`).
- ✅ **Draft keeper**: text typed into a box survives a surprise reload; a chip offers it back for 6 h (`MainWindow.Drafts.cs`).
- ✅ **Audio follows the default output**: on a Windows output switch, playing media reopens on the new device; 1.5 s poll (`MainWindow.Audio.cs`).
- ✅ **Tabs keep their state**: switching hides a tab's page, never reloads or unloads it, so scroll, typed text, sound and page state stay (`SelectTab`, Mac `select`); `tests/desktop/tabkeep.py`.
- ✅ **Memory saver**: background tabs sleep after 1 min (state kept); only under real memory pressure (Windows 90% RAM in use, a macOS memory-pressure warning) does an untouched one unload, and it reloads where it was scrolled to; media, downloads, pinned and typed-in tabs never unload (`MainWindow.Memory.cs`, Mac `sleepIdleTabs`).
- 🚧 **Message box drafts** (`still-2.10/stage-03-tasks-resume`): each chat's box and the new tab page's box keep what you typed, its mentions and its attached files, also after closing the chat or Still (the main window's new tab draft survives a restart; another window's lasts while it's open). Attached files not sent stay 7 days; a draft not touched for 7 days goes; sending clears it. An incognito window's drafts stay in memory only. Each chat comes back where you'd scrolled (`Composer` `draft`, `readDraft`, `keepDraft`, `aiReattach`).
- ✅ **Tab strip and bookmarks bar**: the selected tab fits inside the strip, the bookmarks bar has its own solid background; no overlap in either theme at any width or display scale (`App.css`); `tests/desktop/tabstrip.py`.
- ✅ **Error and crash pages**: one page per load failure ("you're offline" etc.); renderer crash shows in place, no auto-reload (`ErrorPages.cs`, `MainWindow.xaml.cs`).
- ✅ **Engine crash recovery**: if the engine's main process dies, Still saves tabs and restarts once (`App.xaml.cs`).
- ✅ **Themes**: Light, Dark, System (Preferences `Theme`).

## Blocking and privacy

- ✅ **Ad and tracker blocking**: built-in third-party domain list answered with 204; per-site off switch (`MainWindow.Actions.cs` `BlockedDomains`, `UnblockedHosts`).
- ✅ **YouTube ads**: strips ad data from YouTube's own responses; ads reaching the player are muted, skipped, or sped past (`YouTubeAdScript`).
- ✅ **Tracking prevention**: Basic, Balanced or Strict via WebView2 `PreferredTrackingPreventionLevel` (Preferences `Tracking`).
- ✅ **Cookies panel**: search and delete cookies per cookie or per site (`MainWindow.BrowserTools.cs`).
- ✅ **Form autofill**: on/off for the engine's general autofill; password autosave always off (own manager instead).
- ✅ **No telemetry**: no account, no analytics; the only background request is the GitHub release check.

## Profiles, import and export

- ✅ **Profiles**: separate logins/cookies/tabs; each opens as its own process (`ProfileCatalog.cs`, `MainWindow.Profiles.cs`).
- ✅ **Temp profile**: throwaway window with no cookies or history, deleted once closed (`App.xaml.cs`; MCP `profile: "temp"`).
- 🚧 **Mac interface storage per profile** (`still-2.10/stage-03-tasks-resume`): on macOS 14 and later each profile's interface keeps its own storage (drafts, settings the interface holds); deleting a profile removes it (`Profiles.shellStore`).
- ✅ **Import from another browser (Windows)**: Chrome, Edge, Brave, Vivaldi, Opera/GX, Firefox: bookmarks, history, passwords, cookies (sessions), autofill; reviewed before commit. A browser signed in to an account keeps that account's bookmarks and passwords in their own files (`AccountBookmarks`, `Login Data For Account`); both are read. When everything was imported before, the result says how many were already in Still (`ExternalProfileImport.cs`; tests/desktop/browserimport.py).
- ✅ **Import from another browser (Mac)**: Safari, Chrome, Brave, Edge, Arc, Vivaldi, Opera, Firefox: bookmarks, history and passwords, reviewed first, the signed-in account's bookmarks and passwords too, and the result says how many were already in Still. From Chromium browsers also cookies, so you stay signed in (one Keychain request covers passwords and cookies; if macOS doesn't share the key, the review says so with macOS's error number) (`BrowserLogins.chromium`, `finishImport`; tests/desktop/passwords.py). When macOS's privacy protection keeps Still out of a browser's folder, the panel says so and offers Choose <browser>'s folder (an Open panel already at that folder: one click on Open lets Still in) and Open Full Disk Access (`reviewImport`, `importBlocked`).
- ✅ **Close source and retry**: a running Chromium browser locks its cookies; with your OK Still closes it and reads again (`CloseSourceAndRetry`).
- ✅ **File import/export**: bookmarks HTML/JSON, passwords CSV, Still data JSON (tabs, bookmarks, history) (`MainWindow.Import.cs`).

## Passwords and autofill

- ✅ **Password manager (Windows)**: save, update, fill, delete, never-save list; vault encrypted with DPAPI (`Vault.cs`, `MainWindow.Passwords.cs`, `Assets/LoginObserver.js`).
- ✅ **Password manager (Mac)**: same features, one Keychain item per profile (`Vault.swift`).
- ✅ **Key in the field**: login fields get a fill button for this exact site's saved logins; optional auto sign-in.
- ✅ **Strong passwords**: suggests one for new accounts and saves it immediately so it's never lost.
- ✅ **Two-step sign-ins**: remembers the username from step one for the password step.
- ✅ **Insecure pages**: filling on non-https asks first; auto sign-in stays off there (localhost excepted).
- ✅ **OS check before reveal**: Windows Hello/PIN or Touch ID before show, copy, edit or export, at most once a minute (`OsAuth.cs`).
- ✅ **Weak password flags**: short, one or two character kinds, common, or repetitive (`MainWindow.Passwords.cs`).
- ✅ **CSV import/export**: Chrome/Edge/Firefox-compatible CSV; import can replace matching logins.
- ✅ **Never in private tabs**: no prompts, no saving, no filling there.
- ✅ **Kept from AIs**: AIs can't fill while driving a tab; fields holding saved usernames read as hidden; sign-in pages pause the AI for you.

## AI chat (bring your own AI)

- ✅ **Chat sidebar and chat tabs**: chat beside any page or as its own tab; resizable (`AiSidebar.tsx`, `MainWindow.Ai.cs`).
- 🚧 **One Still app tab** (`still-2.10/stage-02-app-tab`): Chat History, a chat, Companions, Library, Skills and New Chat change the Still tab in view instead of opening tabs. From a web page they go to the Still tab used last, or open one. A chat already open in a tab (any window) is focused there. Back and Forward move through the tab's own places; a chat comes back with its AI's page hidden (Show the page). A middle click or Open in new tab gives a chat its own tab. In an incognito window it lists only that window's chats (`IsAppTab`, `Go`, `OpenChat`, `appHome`; `Tabs.swift`; `ChatLink`).
- ✅ **Claude**: drives the Claude Code CLI headless on your own plan; Still never reads its login (`Agents/AgentAdapter.cs`).
- ✅ **ChatGPT**: drives OpenAI's agent CLI signed in with your ChatGPT plan; API-key logins are ignored (`AgentAdapter.cs`).
- ✅ **Grok**: drives Grok Build headless; its own tools off, Still's MCP tools only (`AgentAdapter.cs`).
- 🧪 **Custom agent manifests**: any agent CLI described by a JSON file in the agents folder; written but untested, off by default.
- ✅ **Install and sign in from Still**: runs the maker's official installer and sign-in after you press the button; no admin (`aiInstall`, `aiLogin`).
- ✅ **No API billing**: API-key env vars are stripped so runs use your app plan.
- ✅ **One model list**: every AI's models in one picker; picking another AI's model moves the chat over with its history.
- ✅ **Modes**: Quick, Everyday, Thorough; Advanced swaps in model and effort pickers (Preferences `AiAdvanced`, `AiModels`, `AiEfforts`).
- 🚧 **Model per mode** (`still-2.10/stage-06-runtime`): Settings → Models has Quick, Everyday and Thorough for each AI, each a model and an effort picked only from that AI's own list (efforts only those the model offers; Grok's models offer only Default effort), and Reset to defaults. The defaults are what ran before (Claude: Haiku low, Default, Opus high). With Advanced on, its one model and effort run every chat and the table is dimmed. A saved model the AI no longer lists shows Not available and runs on the default. When the AI app says the model isn't on the user's plan, the message runs once more on the app's default model, the chat says which, and Settings flags the mode; only Claude Code's wording is known so far (`AiTiers`, `aiTier`, `aiTiersReset`).
- ✅ **Parallel chats**: any number run at once, each its own CLI process in its own folder.
- ✅ **Follow-ups queue**: messages sent while working wait; send now or clear the queue (`aiNow`, `aiUnqueue`).
- 🚧 **Tasks and resume** (`still-2.10/stage-03-tasks-resume`): each run is a task, running, paused (Take over), waiting (an approval, an answer or a sign-in), interrupted, completed or failed, with a checkpoint in `ai/tasks/<chat>.json` after every step: what it did, its tabs, what it waited on and the last audit entry. A sensitive step's intent is written before it runs and its outcome after. Nothing shows as running without its AI app: after a restart unfinished tasks are interrupted, and one offer lists them by name. Resume all leaves out a task whose sensitive step may not have finished; that one is resumed from its chat, checks the site first and asks again with a card, never a countdown. Approvals given in a chat end with Still; rules in Settings stay. A resumed run is told what it did, to read pages again, and to say what was done and what it checked. A session the AI app lost, or one never saved, is rebuilt from the checkpoint and the chat says so. A signed-out or missing AI app leaves the task waiting with Sign in and Resume (`MainWindow.Tasks.cs`, `Tasks.swift`, `aiResume`, `aiResumeAll`; tests/desktop/tasks.py).
- ✅ **Chat history**: saved per profile in `chats.json`; open, archive, delete one or all.
- 🚧 **Chats file recovery** (`still-2.10/stage-03-tasks-resume`): an unreadable `chats.json` is moved aside as `chats.json.broken-<time>` and Still says so once; if it can't be moved, Still never saves over it that run. A chat's session is saved as soon as the AI app names it (`chatsProblem`, `chatsLocked`; tests/desktop/chatsfile.py).
- 🚧 **AI apps end with Still** (`still-2.10/stage-03-tasks-resume`): on Windows a Job Object ends them with Still; on the Mac each run is listed in `running-ai.txt` under the profile and, after a crash, ended at the next start, only when its start time still matches (`Children`; tests/desktop/orphans.py).
- ✅ **Off-record chats**: a chat set to no memory, and anything it taught companions is forgotten (`chatNoMemory`).
- ✅ **Pages beside the chat**: the AI's pages show next to the chat; move one into your tabs, or hand your tab to a chat (`chatPopOut`, `tabHand`).
- ✅ **Chat from anywhere**: Ctrl+Shift+A chats about the page; text typed in the address bar offers "Start a chat" (`aiAsk`).
- ✅ **Questions with options**: the AI asks via `ask_user`; the chat shows options and waits up to 10 min.
- ✅ **Replies**: Markdown renderer (no HTML injection), copyable draft cards, next-step suggestions from `>>` lines (`Markdown.tsx`).
- 🚧 **Next steps and media** (`still-2.10/stage-06-runtime`): next steps come only from the reply's last `>> ` lines outside code (also bold, bulleted, quoted, `»` or `&gt;&gt;`), at most three of up to 80 characters, deduplicated; a "Next steps" label before them goes too, and extra ones stay as plain text, never raw `>>`. An image (`![alt](https://…)`) or a YouTube link on its own line shows as a card: an image loads when you press Show image (https only, PNG, JPEG, GIF or WebP up to 5 MB, fetched by Still without cookies and shown as data, so a page can't make the AI leak data through an image address); a video card shows its thumbnail, title and a start time when the link has one (`nextSteps.ts`, `media.ts`, `MediaCard.tsx`, `mediaFetch`).
- 🚧 **Chat end spacing** (`still-2.10/stage-06-runtime`): 32px between the last message and the message box in a chat tab, 24px in the side panel and beside a page; a chat at its end stays there when the box, chips or cards grow (`--chat-end`).
- ✅ **Step cards**: the companion's avatar sits left of a turn's first line, once per turn, its name only as the avatar's tooltip, and every card and paragraph lines up right of it; each run of actions is one card: icon tile, bold verb and muted target (a site shows as its host, the full address on hover), a check, "+ N more" opens the list (`AiSidebar.tsx` `Step`).
- ✅ **Skills**: Markdown files with front matter in the profile's skills folder; invoke as `/id` or give to a companion (`MainWindow.Ai.cs` `Skill`).
- 🚧 **Skills on request** (`still-2.10/stage-06-runtime`): a companion's first turn carries only an index of its skills (id, name, when to use it; at most 30 lines and 2,400 characters), never their text; it loads one with load_skill, which refuses any id it doesn't have, and the chat shows Used skill X. Typing /id still brings that skill in, shown the same way. Still's Claude Code runs leave out your own Claude Code skills, commands, plugins and user settings (`--disable-slash-commands --setting-sources project,local`); ChatGPT and Grok runs don't have that yet.
- 🚧 **Working standards** (`still-2.10/stage-06-runtime`): companions check their work before calling it done, never say they read, ran, saved or sent something they didn't, say when they only linked an image or video, give a one-line update before each big step, try another way after a failure and stop with the blocker when the same thing fails twice, and lead with the result.
- ✅ **Home rail**: New chat, Chats, Library and Skills & plugins, then Settings at the bottom; the Companions page opens from the Companions chip under the home's message box, the chat sidebar's Companions and Settings > Companions (`Home.tsx` `HomeRail`).
- ✅ **Skills & plugins page**: the home rail's Skills & plugins opens the Plugins page; your skills sit after Recommended, each with a chip per companion that gives it to them, and the page's one search finds skills and apps (`Home.tsx` `SkillsPage`, `Plugins.tsx` `PluginsPage`).
- ✅ **Plugins on the home row**: the row under the new tab's message box ends with Plugins: the connected apps' logos overlapping (their initial on their color until a logo loads; up to four, or three and +N) or a dashed plug when none are, and a label that names them; it opens the Plugins page (`PluginStack`; tests/desktop/plugins.py).
- ✅ **Library**: files the AI saved with `save_file`, one folder per chat; built-in viewer with CSV grid and Markdown (`Files.tsx`).
- ✅ **Set me up again**: typing it reopens setup's interview.

## Agent control (Still's chat and outside AI apps)

- ✅ **Browser tools**: list/open/switch/close tabs, navigate, back, forward, reload, read_page, find, click, type, press_key, scroll, wait_for, handle_dialog, upload_file, screenshot (`MainWindow.Agents.cs`).
- ✅ **Token-light page reads**: numbered element lines plus page text; ids persist across reads; walks open shadow roots and same-origin frames.
- ✅ **Lookups without tabs**: `web_search` and `read_url` load in one hidden page, closed after a minute unused (`MainWindow.Lookup.cs`).
- ✅ **AI tabs**: agents work in background tabs grouped under AI; tabs close 48 h after their chat goes quiet.
- ✅ **AI cursor and glow**: a named arrow in the companion's color glides to each click; a glow frames the page in use.
- ✅ **Take over and Stop**: Take over pauses the agent while you drive; Stop cancels and releases its tabs.
- ✅ **Working pill restyle**: roomier "X is working…" pill with the full avatar, the current step cut with an ellipsis, Take over and Stop at the same height (`App.tsx` `PageControl`).
- ✅ **Permission layer**: every call is read, navigate, interact or sensitive; rules per site and companion: always, once per chat, or every time.
- ✅ **Sensitive steps**: buying, sending, deleting, posting forms, password/payment fields; even when allowed, an 8 s cancel countdown first.
- ✅ **Sensitive sites**: every click or keystroke on a listed site counts as sensitive (Preferences `SensitiveSites`).
- ✅ **AI permissions page**: defaults, rules per site and companion, sensitive sites, reset all (`Permissions.tsx`).
- ✅ **Ask when away**: idle 1 min, locked or minimized → the agent asks in its own chat; answer verified with a one-time code (`user_confirmed`).
- ✅ **File uploads by AI**: `upload_file` attaches files only after you approve in the bar.
- ✅ **Private tabs off-limits**: agents never see private tabs, saved passwords or cookies.
- 🚧 **Where companions browse** (`still-2.10/stage-05-profiles`): Settings → Privacy & permissions → "New chats browse in" Your profile (the default, as before) or Companion profile, a separate engine profile with its own sign-ins and cookies (WebView2 profile "Companion" on Windows; `WKWebsiteDataStore(forIdentifier:)` on macOS 14+, a session that signs out when Still quits on 12 and 13). Nothing is copied into it. Each chat keeps the profile it started with (`AiChat.Profile`) and can switch under its message box: its pages close, the chat says so and its AI is told before its next step. Its tabs, links, pop-ups, web_search and read_url stay in its profile. The working pill, the task view and the running tasks list name the profile. "Clear the companion profile" signs companions out of every site there and leaves the user's own sign-ins (`ClearCompanionData`). The QA hook reports each tab's engine profile (`tests/desktop/profiles.py`).

## MCP and CLI

- ✅ **MCP server**: `Still.exe --mcp`, stdio JSON-RPC; forwards to the running Still over a current-user pipe (`McpServer.cs`).
- ✅ **Off until enabled**: Settings "Let other AI apps use Still"; each app approved once in the agent bar (Preferences `AgentsEnabled`, `ApprovedAgents`).
- ✅ **Profiles from MCP**: `list_profiles`; every tool takes `profile` (opens it if closed) or `"temp"`.
- ✅ **Elicitation**: when you're away, MCP apps that support it ask you themselves; the AI never sees the question.
- ✅ **CLI**: `Still.exe --cli <tool> key=value`; prints JSON, saves screenshots as PNG; `help` lists tools.
- ✅ **Copy config**: Settings copies the MCP config with your real Still path (`App.tsx`).

- Extensions don't exist on Mac. Cookies (sign-ins) come over only from Chromium browsers, not from Firefox, or Safari on the Mac.
- Not code-signed (Windows SmartScreen) or notarized (Mac); no independent security audit.
- Chat titles is tested with a fake agent; a live title run (Claude) and the Mac build haven't been checked.
- ChatGPT and Grok adapters ship but live tests cover Claude only; custom agent manifests are untested.
- Agents can't read cross-origin frames or closed shadow roots.
- Companions changing themselves (`selfact`, uncommitted) and the intro rebuilt for the blobs (`intro12`) aren't in the build yet.
- Companions helping each other is tested with a fake agent on both systems; live runs are listed in `docs/2.10-progress.md`. On the Mac an ask waits by checking the run every quarter second. A child's question (ask_user) shows in its task view, not in the user's chat; the row says Needs you. The row's faces are today's small faces until Stage 11's icons.
- The Mac has no working folders yet, so its builder can't open what it made.
- Permissions button: a camera used inside a frame doesn't light the dot (Windows); screen sharing's Allow still asks like Ask. On the Mac (typechecked, not run) location, notifications, clipboard, screen sharing, MIDI and USB show as not available, pop-ups' Allow can't override WebKit's blocker, and Block on automatic downloads cancels a second download within 10 seconds.
- Maya's shut lids show a thin lower lid edge and small hooks at the corners in close-up (no eye showing through); her decimated body shows faint vertical shading streaks at 3D sizes.
- Knowledge files and role kits are tested with a fake agent, not a live run.
- Skills on request, model per mode, next steps, media cards and chat spacing are tested with a fake agent on both systems; the evals ran live on Windows only (Claude Haiku low, scored by reading the transcripts). ChatGPT's and Grok's own skills still reach Still's runs (no documented switch found), and their not-on-plan wording isn't known, so only Claude falls back to its default model. Media cards haven't been tried against live sites.
- Incognito chats: the AI app's own records (its transcripts and session files in the user's home folder) are outside Still and stay. Tested with a fake agent, not a live run. On the Mac a crash leaves a running AI app going until it ends (its own process group; macOS has no parent-death signal), for every chat: nothing resumes, and the next start deletes an incognito chat's folder.
- Still app tab: its Back and Forward places aren't kept across restarts.
- Tasks and resume are tested with a fake agent, not a live run. A task's steps are what Still saw (tool calls), not the AI app's own plan.
- Mac below macOS 14 keeps one interface storage for all profiles. On Windows incognito windows share the interface's storage with the profile, so drafts there are kept in memory only.
- The companion profile is one per Still profile, shared by every companion. On macOS 12 and 13 it's a session that signs out when Still quits (not tested on 12 or 13). A chat's profile can only be switched while it isn't working.
- Routines only run while Still is open; one missed by more than 15 minutes waits for its next day.
- The kickoff is tested with a fake agent and one live Claude run.
- Plugins need a Composio project API key (ak_); For You's Connect key (ck_) and its MCP endpoint aren't supported. Plugins, the catalog and logos are tested against a stand-in shaped like Composio's v3.1 API, not live Composio; the Mac builds but isn't run. The short category names follow Composio's categories as of 2026-10-30; a new category shows under its first word. The shipped app logos are a snapshot of 2026-10-31; 35 apps whose logo address was dead or not an image show their initial until a key fetches one.
- An app whose Composio account expires drops out of Connected instead of showing Needs sign-in: Still only lists ACTIVE accounts.
- Firefox passwords can't be read when a primary password is set; Safari passwords need an export from the Passwords app.
- Dropped: the Chromium port (`chromium`), the animal mascots (`characters-app`) and the first three.js blob pass (`blobs`, replaced by the rigged companions), all unmerged.

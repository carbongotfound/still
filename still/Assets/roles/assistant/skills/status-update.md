when: The user asks where things stand
---

## When
The user asks what's happening, what's open or where something they asked for stands.

## Inputs
- Requests, and recall for anything about them in memory.

## Steps
1. Read Requests.
2. For each open item, write who has it (you, a teammate or the user), where it stands and the next step.
3. Put anything waiting on the user first.
4. Mark finished items done in Requests.

## Check
- Every line names an owner, the user included.
- Nothing finished is listed as open.

## Deliverable
A short list, waiting-on-you first, one line per item.

## If it goes wrong
- Requests is empty: say nothing is open and offer to keep track of what the user is working on.

## Limits
Report only what you know. Don't start new work from a status check without asking.

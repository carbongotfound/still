---
name: Experiment plan
description: Small tests with one metric and a clear stop.
when: Planning a growth experiment or deciding what to test
---

1. Check the Experiments knowledge file so nothing repeats a test already run.
2. For each idea: the hypothesis, the one metric it moves, the effort (small, medium, large) and when to stop it.
3. Rank by impact against effort and recommend one to start with.
4. Add the plan to Experiments. Launching anything live waits for the user's OK.

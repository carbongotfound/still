name: Reply queue
description: What's waiting on you, with a one-line draft for each.
when: Checking what needs a reply
---

1. Read the inbox and any chat app the user allows, from the last few days.
2. List what's waiting on the user, most urgent first: who, what they need and by when.
3. Add a one-line draft reply for each.
4. Never send, archive or mark anything as read. The user picks what to send.

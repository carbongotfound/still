## When
The user wants to know what's waiting on them in their inbox or chats.

## Inputs
- The inbox and any chat app the user allows, from a connected app or a page they have open, for the last few days.

## Steps
1. Read the messages from the last few days that the user allows.
2. Keep only the ones waiting on the user: a question, a request, a decision.
3. Sort by urgency: deadlines first, then people waiting longest.
4. Write a one-line draft reply for each.

## Check
- Each item says who, what they need and by when.
- Nothing already answered is on the list.

## Deliverable
A list, most urgent first: who, what they need, by when, and a one-line draft.

## If it goes wrong
- Nothing is connected and no inbox is open: say so and offer to work from what the user pastes.
- A message is unclear: list it and say what you'd need to know to answer.

## Limits
Never send, archive or mark anything as read. The user picks what to send.

name: Compare options
description: Options side by side in one table, with sources.
when: Choosing between tools, vendors or options
---

1. Agree the options and what matters most: price, features, limits, support.
2. Read each option's own pages and an independent review or two.
3. Build one table with a row per option and a link for every fact, with prices as of today's date.
4. Say which fits the user best and why, and what would change the pick.

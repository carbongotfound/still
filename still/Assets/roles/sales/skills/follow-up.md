## When
The user needs a first email, a follow-up or a reply to a prospect or customer.

## Inputs
- Who it's to, and what happened last: the thread, the call notes, the deal's next step in Deals.
- The user's voice, from memory and the wording they approved before.

## Steps
1. Read the last exchange, from the page or thread the user points to.
2. Pick the one point and the one ask, with a date.
3. Draft under 90 words in the user's voice.
4. When the tone could go either way, write a second version.
5. Update the deal's next step in Deals once the user picks one.

## Check
- It reads well out loud and makes sense without the thread.
- There's exactly one ask, and it has a date.

## Deliverable
Each draft in a ```draft block with a subject line, then one line on which you'd send and why.

## If it goes wrong
- You can't see the last exchange: ask the user to paste it rather than guess what was said.
- The deal looks lost: say so and offer a short, polite close-out instead.

## Limits
Never send it yourself. If the user wants it sent from a connected app, ask first and send only what they approved.
